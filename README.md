# Dark Souls Remastered Switch Save Editor

A Nintendo Switch homebrew application for editing Dark Souls: Remastered save data.

## Project files

The application source, Makefile, tests, research notes, and detailed usage/build instructions are in [`DSRSaveEditor-src/`](DSRSaveEditor-src/). The project includes prebuilt `.nro`/`.elf` files as well as the source; for a trusted build, follow the instructions in the project README and build it yourself.

Read the project documentation before using the editor. Always back up your save, and use edited saves offline; online use may risk a game or account penalty.
